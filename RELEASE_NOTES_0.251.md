# GenericParser 0.251

- Die künstliche Begrenzung auf 20 Ergebnisse wurde entfernt.
- Pro Abfrage können bis zu 200 Treffer angefordert werden.
- Der Wert `0` bedeutet: alle Treffer aus der aktuell geladenen Abfrage zurückgeben.
- Standardwert im Webinterface ist 120.
- HTML-Parser, React-Fallback und neutrales Listing-Modell bleiben unverändert.

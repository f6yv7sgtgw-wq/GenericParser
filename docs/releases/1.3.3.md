# GenericParser 1.3.3

Release date: 2026-08-09  
Build: `gp-133-20260809-1`  
API contract: `generic-parser-module-v1`  
Worker plan: Cloudflare Workers Paid

## Goal

1.3.3 brings the standalone GenericParser UI into the same visual family as the current Evercade and SNES projects. The release concentrates the page hierarchy, moves Log and Diagnose into the top header, removes visible release/technical explanation blocks and prevents enriched Vinted descriptions from expanding cards without limit.

The production-proven 1.3.2 runtime is retained unchanged: the catalog request still enriches at most three Vinted detail pages inline, and remaining details still arrive through serial background batches of three.

## User-visible changes

- Header with shared project mark, compact version badge and top-level `Log & Diagnose` action.
- Search form, actions and status information reorganized as responsive panels.
- Former `Technische Details anzeigen` control removed from the visible interface.
- Dedicated log page receives the same header and panel language.
- Result cards follow the SNES offer layout with larger media, source/traffic badges, condition, price and one clear `Anzeige öffnen` action.
- Vinted descriptions show four lines by default.
- `Mehr anzeigen` and `Weniger anzeigen` expand and collapse the complete cleaned description.
- Lines consisting only of hashtags and trailing runs of at least three hashtag tokens are omitted; a description consisting exclusively of such blocks is not rendered.
- Expanded state survives card re-renders while background detail batches finish.
- Desktop, tablet and phone layouts prevent horizontal page scrolling.

## Description policy

The cleanup is presentation-only:

1. normalize line endings and trim empty lines;
2. remove a line when every token on that line is a hashtag;
3. remove trailing runs of at least three hashtag tokens from an otherwise normal line;
4. preserve normal prose, including prose that contains an inline hashtag;
5. keep the complete API description untouched;
6. clamp the rendered description to four lines until explicitly expanded.

## Unchanged behavior

- Kleinanzeigen 0.44.4 functional search core.
- 0.44.6.5 operational reference.
- 0.45.0 search runtime bridge.
- Matching, traffic-light scoring, extraction and pagination.
- Inline Vinted detail budget of three per catalog request.
- Deferred Vinted batch size of three and serial client queue.
- Evercade and SNES PAL adapters.
- Existing search aliases and `generic-parser-module-v1` contract.
- Paid-worker timing with no artificial search, retry or package wait.
- Anonymous public-web fallback remains fail-open only.

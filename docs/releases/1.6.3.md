# GenericParser 1.6.3

Release date: 2026-08-10

Build: `gp-163-20260810-1`

Status: release candidate; production acceptance pending

## Purpose

1.6.3 fixes the late mobile `Load failed` visible after 819 results in a long
three-platform search. The API-v2 continuation contract already preserved the
next cursor, but Safari transport exceptions were not marked retryable. The
browser therefore paused after the first lost packet even though prior packets
and the continuation token were valid.

## Changes

- classify fetch and response-body `Load failed` exceptions as retryable
  transport interruptions;
- resend the unchanged packet and continuation token with a bounded recovery
  schedule of 250, 750, 1,500, 3,000, 5,000 and 8,000 milliseconds;
- retain zero delay after successful packets on the Paid Worker;
- pause deferred Vinted detail batches while the primary search is running and
  resume them as soon as that search pauses or completes;
- prefer the complete in-memory state when the user resumes on the same open
  page, preserving transient eBay listings without persisting them;
- state explicitly which results remain in memory and which non-eBay results
  plus continuation cursor were stored durably;
- count unique source listing keys instead of adding raw packet rows;
- use one `complete / total` denominator throughout Vinted detail progress.

## Privacy and compatibility

Ordinary eBay search results remain excluded from IndexedDB and from all
server-side storage. Only explicitly selected favorites may be stored in the
browser, as before. Module-v1, module-v2 request/response schemas, signed token
binding, marketplace adapters, product classification, favorites and the
friendly 1.6 interface remain compatible.

## Acceptance gate

The release adds an executable 30-packet browser simulation. Packet 29 fails
once with Safari's `Load failed`; the same packet must then succeed, the cursor
must advance exactly once and all 819 in-memory listings must remain present.
The existing Python, JavaScript, marketplace, CORS, schema and release gates
must remain green. Production evidence will be added after deployment and a
long three-source live run.

Rollback target: 1.6.2 / `gp-162-20260810-1`.

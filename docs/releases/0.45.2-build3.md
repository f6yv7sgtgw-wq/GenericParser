# GenericParser 0.45.2 Build 3

Release-Datum: 2026-08-07  
Build: `gp-0452-20260807-3`  
Modulvertrag: `generic-parser-module-v1`

## Anlass

Build 1 und Build 2 von 0.45.2 verbesserten die Browser-/CORS-Diagnose, führten aber beim Übergang in die FastAPI/ASGI-Schicht zu Cloudflare 1101/1102. Die Suche war damit regressiert.

## Build-3-Prinzip

Build 3 startet direkt wieder vom letzten live funktionierenden GenericParser-0.45.0-Stand `a418c7cd87d06a46453e56ca2e76fba48569222d`.

Der entscheidende Unterschied zu Build 1/2 ist der Startpfad:

- FastAPI/ASGI wird wie in 0.45.0 einmal beim Worker-Start geladen.
- Es gibt keinen Lazy-ASGI-Import innerhalb eines Requests.
- `search_service_v0450` bleibt unverändert.
- Der 0.44.4-Suchkern und die operative Referenz 0.44.6.5 bleiben unverändert.

## Hinzugefügt

- globale CORS-Unterstützung für Browser-Clients
- browserkompatible OPTIONS-Preflights
- `GET /health`
- `GET /version`
- `GET /diagnostics`
- Alias `POST /search` auf den bewährten Legacy-Suchpfad
- Alias `POST /api/module/search` auf die bestehende Modul-v1-Suche
- Request-ID und strukturierte Request-Logs
- Worker-first-Routing für API, Health, Version, Diagnostics und Search
- automatischer Post-Deploy-Livetest gegen den Evercade-Origin
- echter Modul-Suchrequest als verpflichtendes Release-Gate

## Unverändert

- `generic-parser-module-v1`
- `search_service_v0450`
- 0.44.4 Suchalgorithmus
- Matching und Scoring
- Ranking und Preisbewertung
- Kleinanzeigen-Pagination
- sieben Ergebnisse je Arbeitspaket
- normale 5-Sekunden-Pause
- Retry und Recovery
- Evercade- und SNES-Adapter

## Erfolgskriterien

Der Release darf erst als Stable markiert werden, wenn der produktive Worker:

1. `0.45.2` / `gp-0452-20260807-3` über `/health` meldet,
2. `/version` und `/diagnostics` mit HTTP 200 beantwortet,
3. `/api/module/v1/capabilities` mit HTTP 200 beantwortet,
4. alle drei Browser-Preflights für `/api/module/search`, `/api/search` und `/search` erfolgreich beantwortet,
5. ein echtes Evercade-Modul-Arbeitspaket über `/api/module/search` erfolgreich verarbeitet.

## Rollback

Bei jeder Suchregression wird sofort auf den live bewährten 0.45.0-Commit `a418c7cd87d06a46453e56ca2e76fba48569222d` zurückgestellt.

## Goal

Make an interrupted search unambiguous and improve the visual balance of the
filter area without changing search results or marketplace behavior.

## Changes

- Manual stop now displays `Suche pausiert` and explains that the state is
  saved and resumable.
- `search_stopped` records `reason`, `complete:false` and `resumable:true`.
- The log page normalizes earlier contradictory stop events to the truthful
  manual-stop presentation.
- The nine existing filters fill two balanced desktop rows and reflow to
  three, two or one column as the available width narrows.
- The filter panel uses a subtler accent surface, clearer keyboard focus and a
  compact reminder that red results are hidden by default.

## Unchanged behavior

The search core and module-v1 API are unchanged. Kleinanzeigen, Vinted and eBay
remain the three default sources. Classification, green-first grouping,
fixed-price eBay default, known-shipping total-price semantics, explicit
browser-local favorites and the signed eBay deletion endpoint are preserved.

## Verification before production

- Python release and marketplace regression matrix.
- JavaScript syntax, favorites and eBay signature tests.
- Static stop-status and responsive-layout contracts.
- Package build and archive-content check.
- Production deployment gate with all three sources and deferred Vinted detail
  enrichment.

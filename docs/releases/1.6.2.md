# GenericParser 1.6.2

Release date: 2026-08-10

Build: `gp-162-20260810-1`

Status: stable; production acceptance passed

## Purpose

1.6.2 fixes the mobile browser start-up failure reported after 1.6.1. The
search UI must not become permanently disabled because an optional identity or
diagnostic request briefly returns Safari's `Load failed` error.

## Changes

- provide a minimal embedded release identity immediately;
- verify `/health` asynchronously with bounded retries;
- keep module-v2 search enabled when identity diagnostics are unavailable;
- fall back to the direct browser controller if the optional reference
  controller cannot be loaded;
- bypass every dynamic JSON and API endpoint in the service-worker cache;
- never return the cached HTML shell for a failed JSON, JavaScript or CSS
  request;
- move `Log & Diagnose` onto the 1.6 palette and responsive layout;
- render event details as compact expandable cards with practical filters;
- identify the browser route as `generic-parser-module-v2` and module-v1 as
  compatibility only.

## Compatibility

The marketplace search core, adapters for Kleinanzeigen, Vinted and eBay,
module-v1, module-v2, continuation tokens, product classification, favorites,
stop/resume behavior and Paid Worker timing are unchanged.

Rollback target: 1.6.1 / `gp-161-20260810-1`.

## Acceptance

Production workflow `31423346170` passed on commit
`9e2a09b71c6d6cea7bca4e13b0ecd2a515758907`, including live identity, module
API v2, Kleinanzeigen, Vinted, official eBay Browse API, the signed eBay
deletion contract and deferred Vinted details.

A direct browser run loaded 378 unique `Zelda` eBay results over API v2 before
a controlled stop. The UI reported the run as paused and resumable. The live
search and redesigned Log & Diagnose page both showed 1.6.2; index, identity,
controller, app, service worker, eventlog HTML/JS and `ui-162.css` matched the
tested files byte for byte.

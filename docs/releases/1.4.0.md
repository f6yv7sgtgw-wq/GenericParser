# GenericParser 1.4.0

Release date: 2026-08-09  
Build: `gp-140-20260809-1`  
API contract: `generic-parser-module-v1`  
Worker plan: Cloudflare Workers Paid  
Status: Stable

## Goal

Add eBay Germany as a first-class third marketplace source through the official Production Browse API while keeping existing Kleinanzeigen and Vinted behavior stable. Price scoring must not treat unknown shipping as free shipping.

## Changes

- Official eBay Browse search with application OAuth on marketplace `EBAY_DE`.
- Three-source default orchestration with isolated, fail-open source status.
- Fixed-price offers by default; auction-only offers require `include_ebay_auctions: true`.
- Separate `item_price`, `shipping_cost` and `total_price` fields.
- The shared scoring field `price` is populated only with a trustworthy delivered or pickup total.
- eBay source identity, listing format and shipping state in the browser UI.
- OAuth token caching only in Worker memory until expiry.
- No eBay listing persistence in the Worker or bundled browser IndexedDB.

## Compatibility

- `generic-parser-module-v1` remains the stable integration contract.
- Existing request fields and endpoints remain available.
- `include_ebay_auctions` and eBay response fields are additive.
- Kleinanzeigen 0.44.4 functional core, 0.44.6.5 operational reference and 0.45.0 runtime bridge remain in place.
- Existing Vinted Service Binding and bounded inline/deferred detail behavior remain in place.

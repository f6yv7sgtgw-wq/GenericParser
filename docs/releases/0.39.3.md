# GenericParser 0.39.3

## Ressourcenoptimierung

- Jede Worker-Anfrage verarbeitet weiterhin genau eine Kleinanzeigen-Seite.
- Die Antwortzeit jeder Seite wird im Browser gemessen.
- Die Pause vor der nächsten Seite wird automatisch an die gemessene Laufzeit angepasst.
- Der Status zeigt letzte Antwortzeit, Durchschnitt, adaptive Pause und Ressourcentrend.
- Temporäre Fehler werden nach 2 und 5 Sekunden erneut versucht.

## Datenkonsistenz

Jede Seite wird vor der Übernahme geprüft:

- `fetched_listings == pagination.unique_listings`
- `visible_listings == len(listings)`
- `fetched_listings == visible_listings + hidden_by_filter`
- keine doppelten IDs innerhalb einer Worker-Antwort

Zusätzlich gilt kumulativ:

`abgerufen = eindeutig + Duplikate + ausgeblendet`

Bei einer Abweichung stoppt die Suche kontrolliert. Bereits konsistent geladene Ergebnisse bleiben sichtbar.

## Browser-Performance

- Zunächst werden höchstens 80 Ergebniskarten gerendert.
- Weitere Karten können in Schritten von 80 eingeblendet werden.
- Alle geladenen Anzeigen bleiben für Sortierung und Deduplizierung erhalten.

## Versionierung

Worker, Einstiegspunkt, Oberfläche, JavaScript und PWA-Cache verwenden gemeinsam Version 0.39.3.

# GenericParser 1.0.0

**Status:** Stable  
**Release date:** 2026-08-08  
**Build:** `gp-100-20260808-1`  
**API contract:** `generic-parser-module-v1`  
**Worker profile:** Cloudflare Workers Paid

## Purpose

GenericParser 1.0.0 is the first stable production release. It promotes the proven 0.45.2 Build 7 Paid Worker state without changing the functional search core.

## Stable technical baseline

- Search runtime: `0.45.0`
- Functional search core: `0.44.4`
- Operational reference: `0.44.6.5`
- Module contract: `generic-parser-module-v1`
- Evercade adapter retained
- SNES PAL adapter retained
- CORS, diagnostics and route aliases retained

## Paid Worker timing profile

Artificial Free Worker protection waits are disabled:

- new-search cooldown: `0 ms`
- normal packet delay: `0 ms`
- retry waits: `0 ms`
- auto-resume quiet period: effectively immediate
- recovery health interval: effectively immediate

The seven-result work-packet structure remains part of the proven parser runtime. Only artificial waits between requests are removed.

## Compatibility

1.0.0 keeps `generic-parser-module-v1` unchanged. Clients should integrate against this contract rather than pinning an exact internal build identifier. The browser controller accepts the 1.0 and legacy 0.45 release lines during rollout as long as the API contract matches.

## Release policy from 1.0 onward

- Semantic versioning for stable releases.
- Search-core changes require explicit regression tests.
- Infrastructure changes must not silently alter matching, ranking, extraction or pagination.
- Every stable release requires CI, live deployment validation and an exact-source ZIP artifact.
- `VERSION.json`, package metadata, README, changelog, release index and UI/worker identity must be consistent.

# GenericParser 1.3.4

Release date: 2026-08-09  
Build: `gp-134-20260809-1`  
API contract: `generic-parser-module-v1`  
Worker plan: Cloudflare Workers Paid

## Goal

1.3.4 reduces the visual footprint of search results without changing the 1.3.3 feature set. Result cards become a dense responsive grid, their small thumbnail and text remain side by side at every viewport, and the decorative four-dot SNES-style mark disappears from the search-page header.

## User-visible changes

- Result section can expand beyond the form width while remaining inside the viewport.
- Auto-fitting cards use a 250-pixel minimum on larger screens, producing at least three columns on normal desktop widths and four to five columns on wider screens.
- Every card uses a small square thumbnail beside the text instead of a large media block.
- Phone cards retain the same side-by-side relationship with a slightly smaller thumbnail.
- Spacing, badges, title, price, description, metadata and action are proportionally tightened.
- The decorative project mark is removed only from the search page; title, version, connection state and top-level Log navigation remain.
- Four-line Vinted description previews, `Mehr anzeigen`, hashtag cleanup and expanded-state persistence remain unchanged.

## Unchanged behavior

- Kleinanzeigen 0.44.4 functional search core.
- 0.44.6.5 operational reference.
- 0.45.0 search runtime bridge.
- Matching, traffic-light scoring, extraction and pagination.
- Inline Vinted detail budget of three per catalog request.
- Deferred Vinted batch size of three and serial client queue.
- Evercade and SNES PAL adapters.
- Existing search aliases and `generic-parser-module-v1` contract.
- Paid-worker timing with no artificial search, retry or package wait.
- Anonymous public-web fallback remains fail-open only.

## API

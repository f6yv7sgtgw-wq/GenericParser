## Goal

Reduce irrelevant marketplace results before title normalization, make useful
results easier to inspect, and allow deliberate favorites without violating the
eBay data-handling configuration.

## Changes

- Explainable source-independent product classification with Evercade/SNES and
  eBay category signals.
- Hard rejection for clearly mismatched merchandise, accessories, wanted ads,
  rentals and services unless the query explicitly requests that class.
- Unknown product type remains a yellow review case.
- Fixed traffic-light grouping: green, yellow, orange, red.
- Compact filters for traffic light, source, product class, condition, total
  price, shipping, scope and offer format.
- Red results hidden by default, but selectable without rerunning the search.
- Listing description removed from cards; title, header, price, reason and
  shipping remain.
- Decorative logo removed from the log header.
- Star action and dedicated browser-local favorites page.
- eBay favorite snapshots omit seller/account data.
- Separate signed eBay Marketplace Account Deletion Cloudflare Worker with
  challenge validation and ECDSA verification.

## Known production examples

The regression suite contains the false-positive titles observed in the 1.4.0
production PDF:

- `Level 8 Super Mario Kartenspiel Ravensburger NEU`
- `Jakks Super Mario Kart Yoshi in Mach 8 - NEU`
- `CARRERA Pull & Speed Super Mario Kart Mach 8 Mario 1:43`

All three classify as `related_merchandise` and are rejected for a video-game
query. Evercade cartridges, SNES PAL modules, Nintendo Switch titles and eBay
Video Games category matches remain main products.

## Data handling

Normal eBay search results remain transient and are excluded from search-state
IndexedDB. A favorite exists only after a user presses the star and remains in
that browser. It contains no description, seller username, seller ID, feedback
or account identifier. The notification component verifies and acknowledges
deletion messages but stores no notification user data.
